## Deskripsi
Program ini digunakan untuk menghitung panjang sisi miring segitiga siku-siku menggunakan Teorema Pythagoras.

## Rumus
c = √(a² + b²)

## Input
- Sisi a
- Sisi b

## Proses
Program menghitung panjang sisi miring dengan rumus:
c = √(a² + b²)

## Output
Panjang sisi miring segitiga siku-siku.
